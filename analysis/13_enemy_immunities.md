# 敵の免疫値一覧

## 1. 判定仕様

敵テンプレートおよびマップ配置データの`immunities`を一覧化した資料です。

免疫値はビットフィールドです。

| ビット | 値 | 属性 |
|---:|---:|---|
| bit0 | 1 | 炎 (`fire`) |
| bit1 | 2 | 魔法 (`magic`) |
| bit2 | 4 | 打撃 (`blunt`) |
| bit3 | 8 | 斬撃 (`sharp`) |
| bit4 | 16 | 冷気 (`cold`) |
| bit5 | 32 | 電撃 (`electricity`) |
| bit6 | 64 | 銀 (`silver`) |
| bit7 | 128 | 毒 (`poisonous`) |

`immunities`にビットが立っている属性は無効です。免疫値が0は「免疫なし」、255は「全属性免疫」です。

敵へ攻撃する際の元Cソースの判定は次のとおりです。

```c
CHECK_IMMUNITIES(enemy->immunities, Saric.damageType)
```

実質的には次の条件です。

```text
攻撃が通る = (攻撃属性 & ~敵の免疫属性) != 0
```

さらに、攻撃力から敵の`armor`を引いた値が正である必要があります。したがって、免疫を突破しても、攻撃力が防御力以下ならダメージは入りません。
