DS Sound Format Player

Plays .mini2sf / .2sf / .2sflib — Nintendo DS music rips — by running the DeSmuME ARM7 and SPU emulation directly in the browser. A .mini2sf holds only the sequence data, so its companion .2sflib must be available too.

Drop .mini2sf, .2sf and .2sflib files here — a whole rip folder at once is fine.
Library files are registered first, so the order you drop them in does not matter.
Playback uses webDS by Juergen Wothke — an Emscripten port of kode54's vio2sf 2SF decoder, itself built on the DeSmuME emulator. Distributed under the GPL, same as this project. Everything is decoded in JavaScript on this page; no file you drop here leaves your machine.
